# ReaperZxMC - Zenith Launcher Expert Website

## Overview

This is the personal website of ReaperZxMC, a leading expert in Zenith Launcher for running Minecraft Java Edition on mobile devices (iOS and Android). The site serves as a hub for tutorials, guides, and community resources related to Zenith Launcher, Optifine setup, shaders, and troubleshooting common issues.

**Download my Minecraft mod "CoordDisplay" for free on Modrinth:** [https://modrinth.com/mod/coorddisplay/](https://modrinth.com/mod/coorddisplay/)

## Features

- **Animated Background**: Dynamic particle system with canvas-based animations
- **Profile Section**: Rainbow-animated username with bio and avatar
- **Social Links**: Direct links to Telegram, TikTok, YouTube, and support page
- **Minecraft Mod Showcase**: Highlighting personal mod development
- **Responsive Design**: Optimized for desktop and mobile devices
- **Loading Animation**: Smooth loading overlay with progress bar
- **Interactive Elements**: Hover effects, music toggle, and dialogue system

## Technologies Used

- **HTML5**: Semantic markup for structure
- **CSS3**: Custom animations, gradients, and responsive design
- **JavaScript**: Particle animations, loading progress, and interactive features
- **Canvas API**: Background particle effects

## Installation & Usage

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/ReaperZxMC-website.git
   cd ReaperZxMC-website
   ```

2. **Open in Browser**:
   - Simply open `index.html` in your web browser
   - No server required for static content

3. **Local Development**:
   - Use a local server for better development experience:
     ```bash
     python -m http.server 8000
     ```
   - Open `http://localhost:8000` in your browser
